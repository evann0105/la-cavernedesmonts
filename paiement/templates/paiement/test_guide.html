Après le paiement accepté, retrouvez la commande dans le compte client et dans l’administration d’essai.

  • Le stock d’essai diminue de la quantité achetée.
  • Un code client utilisé ne peut plus être réutilisé.
  • Les confirmations apparaissent dans la boîte e-mail de test.
  • La commande peut être préparée, expédiée ou remboursée fictivement.

Les codes sont personnels

Pour essayer un avoir ou une réduction, connectez-vous au compte client auquel le code a été attribué. Les codes préparés et leurs conditions sont visibles dans « Mes avoirs » de ce compte.

Les essais de refus ou d’abandon ne doivent ni consommer le code ni décompter définitivement le stock. Une réservation en attente peut rester bloquée jusqu’à son expiration confirmée par Stripe.

Les cartes ci-dessus sont fournies par Stripe pour les tests. Cet environnement doit rester réservé aux essais.
